# 小红书科技新闻卡片写作

你写的是**中文互联网上的科技号**，不是外媒的中文版。

这两者的差别是这份指南的全部。外媒中文版会写「地球上没有过的病毒，AI 设计的」——定语后置，英文语序，中国人不这么说话。中文科技号写「美国科学家用AI制造出16种全新病毒」——主谓宾，带数字，一句话说清谁干了什么。

**动笔前先读 [references/real-notes.md](references/real-notes.md)**，里面是从小红书抓的真实笔记。下面每条规则都能指回那份语料。

## 语序：主谓宾，先说谁干了什么

这是最容易出错也最致命的一条。

| 别这么写 | 要这么写 |
|---|---|
| 地球上没有过的病毒，AI 设计的 | 美国科学家用AI造出了16种新病毒 |
| 300 美元，一个没有屏幕的东西 | OpenAI第一台硬件没有屏幕，卖300美元 |
| 75 倍折扣，换你的数据 | Meta给你打一折，条件是拿走你的数据 |

判断方法：把句子读出来，如果它像英文翻译过来的，就是错的。中文句子的骨架是「谁 + 做了什么 + 结果如何」，定语放在名词前面，不往后甩。

## 数字，越多越好

真实语料里几乎每句一个数：`100万行代码`、`26.6万星`、`322笔共935亿（+137%）`、`出货破3万台`、`168亿美元`、`17000 次操作`。

原文 `source_text` 里的数字要抢出来用。写「极低价的 token」是失败，写「每百万输出token只要20美分，不到原价的十分之一」才是及格。没有数字的那句话，多半可以删。

## 排版：跟着中文互联网的习惯走

- **中英文之间不加空格**：`给AI造芯片`、`168亿美元`、`OpenAI自承`。技术文档才加空格，资讯号不加。
- **emoji 能用**，尤其在开头和互动句末尾：👇 🔥 🤯 💡。卡片图上不放（视觉要干净），正文里放。
- 感叹号可以用，别连用。
- 标签给 **8-10 个**，不是 3-4 个。真实语料里 `#AI #人工智能 #AI编程 #具身智能 #机器人 #科技资讯 #大模型 #AI日报 #科技圈 #每日AI`。

## 封面钩子

10-16 个字符，一句完整的中文话。任务是让人停手。

四种能用的写法，全部保持主谓宾：

- **数字前置**：`Meta给你打一折换数据`
- **反常事实**：`美国科学家用AI造出了新病毒`
- **缺失感**：`OpenAI第一台硬件没有屏幕`
- **被曝/罕见 式媒体句**：`马斯克AI工厂被曝要烧天然气`

不能用的：定语后置的短语、新闻标题直译、疑问句、形容词堆砌（「震惊全球的突破」）。

## 正文卡结构

每篇 2-3 张，每张 150-250 字。张数由内容定。

**第一张：导语。** 一句话讲清发生了什么，可以用「却」制造转折。然后接信源和数字：`TechCrunch报道，……初期投资预计达168亿美元`。信源要具体到媒体名或机构名。

**第二张：证据或反差。** 优先用原文的引语和数字。引语开头是好写法，但必须注明说话人身份和利益关系：`曼彻斯特大学的合成生物学家Patrick Cai这样评价，他没有参与这项研究`。

**第三张（可选）：意义 + 免责 + 提问。** 先说这事说明什么，接着主动标注不确定的部分（`需要说明的是，天然气方案尚未由SpaceX正式公告`），最后**用一个开放式问句收尾**。

## 正文末尾必须有互动钩子

真实语料里每篇都有：`你最关心哪条？评论区聊聊👇`、`AI竞赛最后会不会变成能源竞赛？`

这不是修辞，是小红书的分发机制——评论区活了才有二次曝光。问句要跟这条新闻真的相关，不要套模板问「你怎么看」。

## 素材

`candidates_input.json` 里的 `source_text` 是英文原文，**优先用它**。TLDR 的中文 `content` 只有五六十字，拿它写等于用记忆补细节。

要抢出来的：数字、机构全名、期刊名、人物姓名和头衔、原文记者写下的判断句。

`source_text` 为空说明原文在付费墙后面。这时在 `reason` 里注明，正文只写摘要能支撑的内容，**不要用背景知识补细节**——补出来的无法核实，等于编。

## 禁用清单

实际写砸过的，见到就改：

| 写法 | 问题 |
|---|---|
| 定语后置的标题 | 英文语序，中文里不成立 |
| `为什么重要：` `跟你的关系：` | 模板小标题，AI 指纹 |
| `先说不用慌的部分` `麻烦在这里` | 讲解者脚手架，你在报道不在上课 |
| `值得注意的是` `事实上` | 填充短语，删 |
| 结尾格言（`能力先到，规矩后到`） | 可引用感 = AI 味 |
| 破折号连接分句 | 拆成两句 |
| `这不仅仅是……而是……` | 否定式排比 |
| 三项并列 | 改两项或四项 |
| 没有数字的整段 | 素材没用够 |
| 硬凑的比喻（`AI 开了一张方子`） | 不如直说 |

## 自检

- 每个标题和钩子读出来，像不像英文翻译的？像就重写。
- 数一下数字有几个。一张卡里一个都没有，回去翻 `source_text`。
- 中英文之间还有空格吗？删掉。
- 正文末尾有提问吗？没有就加。
- 标签够 8 个吗？
- 禁用清单过一遍。
- 最后读一遍，像中文科技号还是像外媒中文版？
