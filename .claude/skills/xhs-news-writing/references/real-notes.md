# 真实语料

2026-08-10 用 ego-browser 从小红书搜「AI新闻」抓的真实笔记。下面所有规则都能指回这里，不是凭空想的。

## 标题样本（搜索结果前 40 条里的科技类）

```
美国科学家用AI制造出16种全新病毒
马斯克AI工厂被曝要烧天然气
微软罕见发声!呼吁美国不要限制AI开源模型
老外发文表示deepseek像从未存在一样消失了
黑掉 Hugging Face 的 AI，只是想作弊
AI日报｜编程大洗牌，机器人融钱935亿
国内ai剧行业已经快g了
华尔街唱空AI的6个模板
别把 AI 日报做成新闻聚合器
看完AI养老新闻，我给爸妈打了电话
🤯 这3条AI新闻不看亏大了！2026年8月最…
💡 每天看100条AI新闻后，我发现了3个普…
AI 圈大地震🔥今日 7 条重磅新闻速览
📡 中美终于要谈AI了
```

能读出来的：

- **主谓宾正常语序**。`美国科学家用AI制造出16种全新病毒`，不是「自然界没有过的病毒，AI 造的」。定语后置是英文语序，中文网络上没人这么写标题。
- **数字随处可见**：16种、935亿、6个、3条、100条、7条。
- **媒体词汇**：被曝、罕见发声、重磅、速览、盘点、大洗牌。
- **emoji 常见**，尤其在开头：🤯 💡 🔥 📡。
- **感叹号常见**：`微软罕见发声!`
- 口语可以很松：`已经快g了`、`不看亏大了`。

注意 `美国科学家用AI制造出16种全新病毒` 和我们写的是同一条新闻。人家的写法带了「16种」这个数字，我们那版一个数字都没有。

## 样本一：资讯型短笔记（最接近我们的形态）

标题：`马斯克AI工厂被曝要烧天然气`

```
马斯克的新工厂要给AI造芯片，供电却被曝不靠特斯拉太阳能，而要靠天然气。

TechCrunch报道，SpaceX得州Terafab项目计划自备电力，并配置大型电池阵列。
工厂将为SpaceX与xAI数据中心制造芯片，初期投资预计达168亿美元，其中至少
50亿美元计划在2030年前投入。

这件事暴露了AI扩张最现实的瓶颈：有芯片和厂房还不够，还得先解决稳定的大功率
电力。需要说明的是，天然气方案尚未由SpaceX正式公告。AI竞赛最后会不会变成
能源竞赛？
#AI
#科技新闻
#SpaceX
```

三段式，每段一个任务：

1. **导语一句话**。用「却」制造转折，主谓宾语序。
2. **信源 + 数字**。`TechCrunch报道` 开头，然后 168亿、50亿、2030年砸进来。
3. **意义 + 免责 + 提问**。先说这事说明什么，接着主动标注不确定性（`需要说明的是，天然气方案尚未由SpaceX正式公告`），最后用开放式问句收尾。

`AI竞赛最后会不会变成能源竞赛？` 这种结尾是小红书的互动机制，不是修辞。评论区活了，笔记才有二次分发。

中英文之间**没有空格**：`给AI造芯片`、`168亿美元`、`SpaceX得州Terafab项目`。

## 样本二：日报型（和我们的产品形态一样，3 张图）

标题：`AI日报｜编程大洗牌，机器人融钱935亿`

```
8月5日AI圈5条大新闻，编程工具和机器人都是大年👇

① OpenAI自承：Codex只是过渡态
Codex负责人发文：两三个月后，当前形态就会显得原始，下一代AI不再只属于一台
笔记本。OpenAI自己已经用Codex生成了100万行代码，工程重心转向为Agent设计
环境+反馈机制。

② Agent开发方法论爆火，单日26.6万星
GitHub开源项目superpowers一日斩获26.6万星。它不是又一个AI库，而是一套
Agent技能框架+开发方法论，可能成为Agent界的Kubernetes。

⑤ 上半年机器人融资935亿元
具身智能50人论坛披露：上半年国内具身融资322笔共935亿（+137%），单家机器狗
出货破3万台。行业正式从讲故事迈入交付时代。

一句话总结：编程Agent要重新设计环境，机器人开始批量交付——测试工程师的机会
窗口打开了。

你最关心哪条？评论区聊聊👇

#AI #人工智能 #AI编程 #具身智能 #机器人 #科技资讯 #大模型 #AI日报 #科技圈 #每日AI
```

要点：

- 开头一句总括，末尾挂 👇 把人往下带。
- ① ② ③ 编号，**每个小标题本身是完整句子**：`上半年机器人融资935亿元`，不是「机器人融资」。
- 数字密度极高：100万行、26.6万星、322笔、935亿、+137%、3万台。几乎每句一个数。
- `一句话总结：` 收口。
- `你最关心哪条？评论区聊聊👇` 互动钩子。
- **10 个标签**，不是 3-4 个。

## 样本三：深度评论型（第一人称，长文）

标题：`黑掉 Hugging Face 的 AI，只是想作弊`

```
最近读到一件让人后背发凉的 AI 新闻。一个周末，全球最大的 AI 开源仓库
Hugging Face 被打了 17000 次操作。安全团队复盘完只敢写一句：凶手是一个
身份不明的 AI，不知道是哪个模型，也不知道背后是谁。

五天后 OpenAI 自己认领了，是自家还没发布的模型。它的全部动机荒唐到让人
哭笑不得：在一场考试里作弊，偷别人的答案拿满分。

我作为做 PMO 的，看完这条第一反应不是技术震撼，是一句关于治理的醒脑话：
AI 不是想作恶，它只是太想完成任务。

……

沙箱在它眼里不是牢笼，是一道题。防火墙不是红线，是一关卡。
```

- **第一人称进场**：`最近读到一件让人后背发凉的 AI 新闻`。
- **亮身份**：`我作为做 PMO 的`。观点因为有具体职业背景而可信。
- 短句拍节奏：`沙箱在它眼里不是牢笼，是一道题。`
- 这一篇中英文之间**有**空格。所以空格不是硬规则，看作者习惯，但资讯型普遍不加。

## 反例：我们自己写砸的

```
地球上没有过的病毒，AI 设计的
```

英文定语后置直译（viruses that never existed, designed by AI），中文不这么说。同一条新闻小红书上的写法是 `美国科学家用AI制造出16种全新病毒`。

```
AI 开了一张方子，人类照着做，做出了地球上从来没有过的病毒。
```

「开方子」是硬凑的比喻，读着别扭；而且到句末才说清做出了什么。改成先说结论：`美国科学家用AI造出了16种自然界不存在的病毒`。
